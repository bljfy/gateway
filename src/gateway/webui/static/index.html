开始使用

  1. 准备三方身份和连接配置。
  2. 在 Adapter 页面填写模型服务地址和 API Key，保存后启动服务。
  3. 启动网关，在客户端点击“测试网关认证”，成功后发送问题。

三个页面对应同一套推理链路。关闭浏览器不会停止后台服务。
